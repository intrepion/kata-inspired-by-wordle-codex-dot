# Evil: a deterministic adaptive variant with unrestricted guesses

Evil is a third game variant beside Daily dispatch and Practice, not a fourth clue-enforcement difficulty. Following the user's clarification, it always uses Normal dictionary validation. Hard/Strict controls are hidden with an explanation; switching variants does not change saved Daily/Practice difficulty or the future-puzzle preference. Normal input length, dictionary, repeated-guess and terminal-run checks still apply.

Start with the existing current curated answers. For each valid guess, score it against every surviving candidate using the unchanged duplicate-aware scorer. Group candidates by their five feedback clues and keep the largest group. Compare equal-size groups by avoiding all-green if a nonwinning group ties, then by ascending left-to-right pattern encoded as absent=0, elsewhere=1, exact=2. Candidate order and the eventual reveal representative are alphabetical. No randomness, lookahead, solver, or invented feedback is used. Every retained candidate produces every previously shown row. The strategy maximizes immediate surviving count; it does not certify an optimal strategy or literal impossibility.

The internal `answer` field is only the first survivor, used to reuse existing clue/keyboard machinery; it is not a preselected target. No representative is shown while playing. Win only when the selected row is all green; six accepted guesses otherwise close the round. On a loss, clearly reveal one surviving example and the remaining count, without saying it was selected beforehand. The UI shows live candidate counts and explains adaptation.

Save the current Evil round separately from Daily and Practice under the existing v1 notebook, with its own versioned guess/draft snapshot. Reconstruct candidates, representative and all feedback by deterministic replay from the full pool on reload. Ignore untrusted cached candidates/feedback/answer/difficulty flags. Reject malformed, duplicate, overlong or post-terminal histories by resetting only Evil. Invalid drafts normalize to empty. Preserve the round across UTC rollover and mode switching; its terminal outcome is saved/derived independently and cannot be recorded as a daily result. Shares identify Evil/adaptive/Normal guesses and surviving count, with no daily date or answer spoilers.

A new Evil round resets only that round to the same starting pool/rules. Ask before replacing unfinished guesses/draft. The current terminal result remains available until starting another round; no lifetime Evil history, separate statistics, or strategy certification is introduced. Daily ledgers and streaks remain unchanged. Existing save formats without Evil state initialize a fresh adaptive round.
