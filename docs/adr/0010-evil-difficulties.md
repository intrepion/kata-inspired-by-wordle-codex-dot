# Evil with independent Easy, Normal, Hard and Strict difficulties

The latest user request supersedes Evil’s former Normal-only restriction. Navigate Evil → Settings → Difficulty. Evil’s current run stores its own difficulty and new rounds retain that choice; changes never overwrite Daily, Practice or their preference. Existing compatible snapshots with no difficulty resume Normal, including Impossible/Evil wire aliases. Schema and answer dataset remain v2; no reset is needed for this feature. Malformed difficulty names degrade to Normal; forged Hard/Strict histories that violate those restrictions reset only the adaptive round through existing corruption handling.

Normal and Easy allow unrestricted accepted guesses. Easy enables the same five Optimal suggestions based on public adaptive clue rows. The pool is reconstructed from all3,493 historical answers consistent with those rows, matching Evil’s survivors exactly; the representative answer is never used for advice. All11,193 accepted words remain the search universe, including exploratory guesses. Suboptimal remains optional, off by default, available at every difficulty and in every mode. Worker cancellation/cache behavior is unchanged.

Ordinary and adaptive games share a pure clue-constraint validator. Ordinary code passes scored revealed rows; Evil passes its actual recorded feedback. Hard preserves greens and minimum positive copies from the previous accepted row, without gray exclusions or forbidden yellow positions. Strict reproduces all previous feedback, including yellow positions, gray exclusions and duplicate maximums. Every surviving answer satisfies both restrictions, so validation cannot exhaust the adaptive pool. Dictionary/input/repeat errors and restriction errors preserve the draft, history and candidates. Largest-bucket scoring, deterministic ties and six-turn rules remain unchanged.

Hard/Strict upgrades require no accepted guesses; downgrades are allowed anytime. Easy can be enabled on an unfinished round, including midgame. Enabling Easy or Suboptimal permanently marks Assisted even if advice is later canceled or disabled. Normal downgrades and reload preserve it. Easy cannot newly label a completed round. Shares identify Evil, adaptive, the current difficulty and assistance. This describes current clue restrictions, not certification that a stricter difficulty was maintained from beginning to end; the existing downgrade policy is retained.
