# Optional on-demand word definitions

The user requested meanings for unfamiliar accepted words, including old guesses. Use the live English Wiktionary experimental structured definition endpoint, with explicit CC BY-SA4.0 attribution, entry/license links and formatting/selection notice. Primary capability docs: https://www.mediawiki.org/wiki/Wikimedia_REST_API . License/terms: https://en.wiktionary.org/wiki/Wiktionary:Copyrights and https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use . Live ABBEY response and CORS headers verified2026-10-24. The Free Dictionary API returned HTTP530 during evaluation; no dependency or code from that GPL project was copied. A bundled comprehensive dictionary was not readily available without a larger import/provenance exercise; this integration downloads no dump and requires no key/account/cost. The endpoint is experimental and can fail; no total coverage claim is made.

Submitted rows are native buttons with an accessible word/feedback label. Suggestions have separate Define buttons that never submit or edit a guess. A revealed-answer button appears only after completion, including Evil’s disclosed surviving example. No draft, hidden answer or candidate-list lookup actions are exposed. Old guesses acquire actions from restored game state. A public-word visibility guard permits only guesses, current visible suggestions and an explicitly revealed result.

The separate native modal first explains privacy and makes no request. The player activates Look up online for the selected word. Requests omit credentials/cookies and referrer, include only the word in the path plus a generic application identifier, and inevitably expose normal network metadata such as IP address. No game state or user identifier is sent. No prefetch, hover request, analytics or per-keystroke query. This user-authorized data lookup is the exception to the project’s otherwise local asset model.

Client normalization accepts only five ASCII letters. English structured senses are bounded and rendered only using textContent. A pure text extractor removes source markup/script/style content, decodes basic entities, drops media/examples/links and preserves plain text; received HTML is never inserted into the document. URLs are constructed from a fixed Wiktionary origin and validated word, not external payload links. Returned content is data, not instructions. Selected senses remain under CC BY-SA4.0; application code remains MIT.

A180ms debounce, per-word pending request deduplication, six-second timeout, AbortController and generation checks prevent stale updates and unnecessary work. Session close/switch cancels requests, including late responses from implementations that ignore abort. In-memory LRU64 caches successes24hours and missing English entries5minutes; network errors are not cached. No new storage/save schema is needed. Reloaded guesses work but definitions must be fetched again. The endpoint may change or be unavailable; missing English entries and network/timeout/invalid responses are reported honestly. Manual retry is offered for failures, without automatic retry loops.

Escape/Close cancels and restores focus to the original control, a replacement visible control for the same word, or the active mode when the trigger disappeared during render/rollover. Keyboard game input pauses while the dictionary modal is open. The modal does not mutate drafts, accepted guesses, candidates, score, difficulty, assistance or save state. Existing game/advice worker behavior and source attribution and all game-state invariants remain unchanged.

## Superseded interaction

ADR0016 replaces the manual local-first modal/Define interactions with user-authorized automatic inline lookups of displayed words. Source, license, sanitization, privacy payload and game-state invariants remain unchanged.
