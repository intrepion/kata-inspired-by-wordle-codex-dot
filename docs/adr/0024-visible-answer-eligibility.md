# Visible answer eligibility

Only words already displayed as submitted guesses, suggestions or revealed answers receive this label. Membership comes from the actual language/length answer pool, independently of current clues and of optional teaching records. A Yes does not certify current clue viability. Counts remain surviving compatible possible answers.

The English removal manifests record pinned AGID/reviewed exclusions; plural and past-tense reasons are presented only for these entries. No suffix inference, frequency claims or grammar classification from dictionary prose is used. Other omissions, including Spanish accepted forms without reviewed exclusion metadata, use an explicit valid-guess/not-selected explanation. Spanish starter answer coverage is finite; independent noun/adjective senses retain Yes if included.

Eligibility renders even while definitions load, fail or are missing and when teaching fields are absent. All text is plain DOM text. Translation/example content precedes eligibility; definitions and attribution follow it. No hidden answer, remaining answer list, gameplay, data pool or reset epoch is changed.
