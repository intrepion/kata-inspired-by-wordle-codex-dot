# Source-bound subject and construction review

Frozen research scopes and independently authored model decisions. Input hashes bind the exact review cases; cross-reviews preserve revisions and disagreement rather than silently merging source roles. These are not native-human or exhaustive linguistic certifications.

Each `audit-N.json` is a collection with two separately identified components: `english` contains selected English Wiktionary material (CC BY-SA 4.0, Wiktionary contributors); `morph` contains Apertium-derived lexical/form records (GPL v2, Apertium contributors). Their original source manifests, complete corresponding Apertium dictionaries/notices, AGID terms and Wiktionary attribution are retained elsewhere in this repository. Model annotations and source quotations retain the applicable component provenance; no single-file MIT claim overrides those data terms. Cross-case provider fields identify the same components.

The restrictive compiler is independently written application tooling under the project's own code license. It adds no lexical meaning. The presence of separate data files does not by itself resolve any combined-work distribution boundary; this local update does not assert a blanket relicensing of independently written application code.
